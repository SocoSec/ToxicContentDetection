# data/

This folder holds datasets, which are **not committed** (see `.gitignore`).

## raw/
Download the source datasets here before running the pipeline:

- **Davidson et al. (2017)** — `labeled_data.csv`
  https://github.com/t-davidson/hate-speech-and-offensive-language (public, no login)
- **Kaggle Cyberbullying Classification** — `cyberbullying_tweets.csv`
  https://www.kaggle.com/datasets/andrewmvd/cyberbullying-classification (free login)
- **HatEval 2019 (English)** — `hateval2019_en_train.csv`
  https://github.com/cicl2018/HEval

`src/dataset_loader.py` auto-detects whichever files are present and merges them.
With none present it falls back to a small synthetic sample.

## processed/
Generated by the pipeline (`dataset.csv`, `train.csv`, `val.csv`, `test.csv`).
